# Project workflow

- After completing requested development and the relevant validation, commit the changes clearly and push the current development branch to origin. The user has explicitly authorized this as the default; do not wait for another reminder to push.
- Report the pushed branch and commit. If authentication or network access prevents pushing, report the actual blocker; never claim success without verification.
- This preference does not authorize force pushes, deleting remote branches, or merging into main without a separate request.
