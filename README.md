# 商品键盘

## 0.1.10 触碰键盘外区域时收起

长按「全清」→ 设置 →「触碰键盘外区域时收起」。默认开启，关闭后恢复原行为；选择自动保存，不受恢复默认大小或恢复自定义候选影响。

开启时，手指触碰键盘上方的表格等键盘外区域就收起键盘，不需要等拖动；普通单击外部区域也会触发，不限定截图中的表格或某个应用。输入内容不会清空，当前输入法不切换。键盘内部的数字、候选和设置操作不触发此功能。

使用 Android 的外部触摸通知，不新增悬浮窗、无障碍或联网权限，不覆盖或拦截表格区域。由于通知只有最初按下事件，不能区分外部单击与拖动。目标应用可能在点击输入框时重新显示键盘，具体行为需在手机与目标应用验收。

## 0.1.9 连续输入优先

型号候选的选区/光标文本查询、收起状态文本检查和型号匹配移到独立后台线程。连续输入仍合并到约 80 ms 空闲后再查询，但不再由主线程等待候选查询返回；数字按下立即提交及高亮规则保持不变。

后台最多保留一个执行中的查询和一个最新待执行查询。后续输入、切换面板、关闭键盘会使旧结果失效；旧查询即使迟到也不会覆盖新候选。候选仍按原包含匹配规则、型号库顺序显示最多 30 项，触摸期间不改变候选栏布局，选择候选成功后立即收起。未增加输入历史存储。

模拟器使用 20000 条型号库，在实际输入框连续输入 20 组 `0891121`，140 个字符完整；并确认停顿后候选正常显示。另验证故意阻塞的候选查询不阻塞主线程点击、过期结果被丢弃。实际手机和目标应用仍需体验确认，不承诺固定毫秒延迟。

## 0.1.8 修复数字键亮起却漏字

数字 0–9 和减号改为按下即提交一次，松开不重复提交；按下后的滑动、离开键帽或触摸取消不撤销已经输入的字符。这样快速点击 `089` 时，手指在 `8` 上按下后略微滑出也不会漏掉 `8`。高亮继续跟随按压状态。同一数字键收到额外手指按下时也按次提交。

全清、自定义、退格、搜索仍按松手判定，保留全清和自定义的长按功能。手指触摸键盘期间暂缓型号候选刷新及高度变化，松开后再更新，减少连点时布局变化的干扰。

模拟器实际输入框对照：旧版在带边缘滑动的 `089` 序列中漏字，修复版相同操作连续 20 组完整输入。第三方应用与具体手机上的手感仍需实测。

## 0.1.7 快速连点与触摸反馈

主键盘按下即高亮、松手即恢复，取消长尾波纹和普通按钮的延迟点击；每次有效松手立即提交，不对重复数字去重或限流。手指滑出按键或系统取消触摸时不输入。自定义键与全清的长按仍只打开对应面板，不额外输入或清空。

连续输入期间合并型号候选刷新：最后一次输入或选区变化约 80 ms 后匹配，文字提交本身不等待这段时间。结果不变时复用候选栏，不反复删除重建按钮或调整高度；没有型号库或关闭候选时不读取选区和光标前文本。选择型号后的收起行为保留，数字布局、大小、排序及自定义内容不变。

## 0.1.6 选中候选后自动收起

点击型号候选并成功填入后，整条候选栏立即隐藏，释放其占用高度。再次输入、退格或修改文本后，重新匹配并显示候选；移动光标、返回键盘或重新打开键盘不会单独触发恢复。仍使用包含匹配，空输入、无匹配及关闭候选开关时不占候选栏空间。导入型号和已有设置保持不变。

自动收起状态仅保留于当前输入法进程，不写入输入历史。支持完整文本提取的应用中，也可通过文本变化发现粘贴等外部编辑；不支持文本提取的应用仍可通过本键盘输入或退格恢复候选。通过离线状态测试、编译及签名检查，真机交互待验收。

## 0.1.5 包含匹配

型号匹配由「开头匹配」改为「包含匹配」。例如输入 `13`，`413`、`c-1357`、`1301` 都能显示。仍忽略英文字母大小写，沿用型号库顺序，最多显示 30 项。空输入不显示候选；候选开关、导入型号、点击替换当前型号的行为不变。升级保留已导入型号及设置。

## 0.1.4 型号匹配候选栏

长按「全清」进入设置，可切换「输入后显示型号候选」（默认开启，自动保存）。候选栏位于键盘顶部；输入型号前缀时显示最多 30 个匹配项，左右滑动查看更多。点击后用完整型号替换光标所在的型号，不会把完整型号重复追加到前缀后。匹配忽略英文字母大小写，输入时保留型号原样。候选顺序沿用导入表格顺序。空输入、无匹配、选中文本或密码输入框不显示候选；关闭开关后整栏隐藏，不占空间。

首次使用：设置 →「导入型号」→ 选择 `.xlsx` 表格 → 选择型号所在列 → 核对预览和「跳过首个非空单元格（列标题）」→ 保存。只保存选中列的型号，去除重复值和无效值；保留文本型号的前导零，也支持纯零数字格式。导入成功替换原型号库，取消或读取失败保留旧数据。支持最多 20000 个型号，每个不超过 128 个字符且不能含空白。表格解压后最大 24 MB；加密文件不支持。

型号库仅保存在手机本地，不随源码上传。安装包不内置用户表格。当前型号以空格、换行等空白分隔；光标处于型号中间时点击候选，会同时替换该型号的前后部分。关闭开关不会删除已导入型号，也不影响长按自定义键打开的固定候选列表。重置自定义候选不会清除型号库。

验证：型号前缀、大小写、空输入、光标边界、表格列读取、前导零、科学记数法、重复项和外部实体拒绝已通过离线测试。当前环境无法启动设备调试连接或标准构建守护进程，本次安装包使用本机安卓开发工具编译、打包并验签；实际手机和表格应用中的操作仍需验收。

## 0.1.3 通用自定义键

原“组合”和“字母”升级为两个能力相同、候选独立的自定义键。初始键帽为 `zp`、`c`；选择什么就显示并输入什么，保留大小写，不附加功能名称。每项支持 1–10 个字符，可添加、修改、删除及拖动排序。旧版候选、固定值、功能列位置与顺序自动沿用。数字区、搜索、全清、减号、退格、大小和震动行为不变。

## 布局自定义

长按全清 → 设置 → 按键布局。点击顶部的功能列位置按钮切换左右；长按功能键，拖到目标键上松开即可调整上下顺序。数字区的位置、宽 0 和搜索功能保持不变，候选区的功能也不变。

编辑面板只调整布局，不输入文字。点击“保存”后应用并在本机记住；“取消”、关闭键盘或切换输入框会放弃尚未保存的修改。“恢复默认”先将预览恢复为左侧的全清、自定义 1、自定义 2、减号、退格，再点击保存生效，只影响布局，不影响大小、候选和震动。五个功能键始终保留，换位置后原有单击和长按行为不变。设置可滚动，横屏采用同一已保存布局。

0.1.1 更新：右下角 00 改为搜索，保留宽 0。键盘、候选、设置和启用页统一为夜间深色，搜索字样用青绿色突出。启用页试输框可验证搜索操作，显示“已收到搜索操作”。

用于商品型号快速输入的 Android 系统输入法（IME），版本 **0.1.10 测试版**。不是商品数据库或搜索软件；输入内容交给当前应用处理。最低 Android 8.0（API 26）。原生 Java 实现，无第三方运行时依赖。

## 布局与操作

默认功能列在左侧，占四分之一宽度，分为五个等高按键：**全清、自定义 1、自定义 2、减号、退格**。右侧占四分之三宽度，四行数字：

```text
1    2    3
4    5    6
7    8    9
0（两格） 搜索
```

左右区域总高度一致，左五行与右四行分别分配高度。

| 按键 | 单击 | 长按 |
|---|---|---|
| 全清 | 立即清空当前输入框，无二次确认 | 打开设置，不清空 |
| 自定义 1（初始 `zp`） | 原样输入当前固定内容 | 打开自定义候选及编辑入口 |
| 自定义 2（初始 `c`） | 原样输入当前固定内容 | 打开自定义候选及编辑入口 |
| 减号 | 输入 ASCII `-` | 无额外操作 |
| 退格 | 删除选中内容或光标前一个 Unicode 码点 | 无连续删除功能 |

两个自定义键的键帽只显示当前内容本身，例如 `zp`、`A12` 或 `+`；不附加“组合”“字母”“自定义”。长内容自动缩小字形并最多分两行显示。原 00 键已改为搜索键：向当前输入框发送 Android 搜索动作（IME_ACTION_SEARCH），不输入文字或换行。目标应用必须支持该动作；请先聚焦应用的搜索框，键盘不会自动打开 Google 表格的查找功能。主界面不放额外工具栏。

## 候选编辑

长按任意自定义键，点击候选将其设为固定值并返回键盘；选择本身不输入文字。点击“编辑”管理这个位置独立的候选：点击内容选为固定值，点击“修改”更改原项，点击“删除”移除，长按 `↕` 拖到目标候选上松开以调整顺序。“添加自定义”新建候选。

添加和修改在深色文本编辑页进行，支持任意字符类别，例如 `z`、`zp`、`1234567890`、`A12`、`+−×÷`、`a,b`、`￥`、`你好`、箭头和表情。按 Android Unicode 字素边界计算 1–10 个字符（普通表情、组合附加符不按 UTF-16 长度重复计数）；不同 Android 版本对新复合表情的边界识别可能不同。原样保留大小写、空格与换行，不自动转小写或裁剪。计数超限或空内容不能保存。

编辑页提供常用符号快捷插入和“切换输入法 / 输入中文”按钮，可用已安装的中文等输入法输入，也可由用户主动粘贴。保存或取消返回原应用；如切换过输入法，需在系统输入法选择器中切回商品键盘。未保存的修改不影响候选，屏幕旋转保留编辑草稿。

重复项不能保存；每个位置至少保留一项。修改固定项会同步更新其固定内容并保留顺序；删除固定项后选用剩余第一项。候选列表使用 JSON 保存，逗号、引号、反斜线、中文等内容可完整往返，兼容读取旧版字母候选。两个位置相互独立，列表、顺序、固定值保存在本机。

**默认候选来源尚未完成：**本工作区没有收到原表 `share_file(9).xlsx`，因此暂时只用需求明确允许的 `zp`、`c`，遵循“宁少不要多”。它们不是统计结论。收到原表后需按型号列统计连续字母组合与单字母的频次，记录取舍，再更新默认值；不将原始商品表提交到公开仓库。

## 设置

长按全清进入：上下拖动大小区域，上拖增大、下拖缩小，松开保存；返回键盘查看效果。尺寸范围为可用基准的 65%–100%，宽高、间距与字形随比例变化，字体保留可读下限。横屏限制键盘基准宽度，居中显示，不启用全屏编辑模式。

按键震动默认关闭，开启后使用系统触觉反馈（效果取决于设备支持）。声音始终关闭。支持恢复默认大小、恢复默认候选（会移除自定义项并重置当前选择）、切换其他输入法。

## 隐私

- 不申请 INTERNET、无障碍或剪贴板权限；没有广告、统计、联网代码。
- 不自动读取系统剪贴板；文本编辑页允许用户主动使用系统粘贴。拖动候选使用 Android 拖放数据载体 `ClipData`，不会读写系统剪贴板。
- 不保存实际输入历史。只保存布局位置/顺序、大小、震动、候选列表/顺序和两个自定义键的当前固定内容。
- 本地配置使用应用私有 SharedPreferences；关闭系统备份。启用界面的试输框不保存文本状态。
- 全清通过当前 InputConnection 的全选和空文本替换完成，不使用剪切。退格仅临时查询当前选区，不记录内容。
- Android 启用输入法时的通用警告是系统提示；本项目的权限与行为可检查源码和 APK 清单。

## 安装与启用

下载 debug APK 到手机，按系统提示允许相应来源安装，安装后打开“商品键盘”：
1. 点击“启用商品键盘”，在系统输入法列表开启。
2. 点击“切换到商品键盘”并选中。
3. 在试输框测试，或切到 Google 表格等应用输入。

测试 APK 由调试密钥签名。不同电脑或不同 GitHub Actions 运行可能使用不同调试密钥，不能保证互相覆盖安装；发生签名冲突时需卸载旧版（本地配置会丢失）。正式发布前应建立固定签名密钥和安全保管流程，密钥不进仓库。

## Google 表格使用

先选中单元格，再进入单元格/公式栏的文字编辑状态，确认键盘出现后输入。全清作用于当前编辑框，不是清空整张表。单元格尚未进入编辑状态时，输入法无法修改单元格。前导零或型号自动转换可通过将目标列设为纯文本处理；完成编辑使用 Google 表格自身的确认控件。

第三方应用可自行实现输入连接；全选、删除与光标行为必须在实际手机版 Google 表格中验收，未宣称已完成该实测。

## 构建

使用 JDK 17 或 21、Android SDK Platform 35、Build Tools 35.0.0。AGP 8.8.0，Gradle Wrapper 8.10.2。首次构建需联网下载构建依赖；**应用本身不联网**。

在 `local.properties` 填入本机 `sdk.dir`（不提交），或设置 `ANDROID_HOME`。

```sh
./gradlew assembleDebug assembleDebugAndroidTest lintDebug
# Windows
gradlew.bat assembleDebug assembleDebugAndroidTest lintDebug
```

安装包：`app/build/outputs/apk/debug/app-debug.apk`。有专用测试设备时运行 `connectedDebugAndroidTest`，详见 [测试说明](docs/TESTING.md)。

GitHub Actions 对 main、feature 分支提交和 PR 自动构建，也支持手动运行。在仓库 Actions 中打开成功运行，下载 `product-keyboard-debug-…` 构建产物并解压取 APK。工作流同时上传 Lint 报告。

## 已知限制

型号表统计待原文件补充；Google 表格和不同厂商设备兼容性需真机验证。全清依赖目标编辑器支持全选：不支持时提示，不擅自删除局部内容。横屏可用但优先优化竖屏；候选面板在小尺寸下较紧凑，较长列表可滚动。无内置商品搜索引擎、词频学习、云同步、语音、日常全键盘、回车键或长按连续退格。震动受系统和硬件限制。此 APK 是调试测试包，不是已完成真机验收的正式版。
