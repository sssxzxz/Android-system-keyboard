# 商品键盘

用于商品型号快速输入的 Android 系统输入法，当前 **0.2.0 测试版**。最低 Android 8.0（API 26），原生 Java，无第三方运行时依赖。输入内容交给当前应用处理，不提供商品数据库或联网搜索。

## 5 列 × 5 行默认布局

整个键盘占 25 个格子，共 24 个按键（0 横占两格）。原来的数字、宽 0 和搜索组成的 3×4 区域整体位于右上角；全清在左上角。

| 第 1 列 | 第 2 列 | 第 3 列 | 第 4 列 | 第 5 列 |
|---|---|---|---|---|
| 全清 | 自定义 3 | 1 | 2 | 3 |
| 自定义 1（原 A） | 自定义 4 | 4 | 5 | 6 |
| 自定义 2（原 B） | 自定义 5 | 7 | 8 | 9 |
| 减号 | 自定义 6 | 0（横跨两格） | ← | 搜索 |
| 退格 | 自定义 7 | 自定义 8 | 自定义 9 | 自定义 10 |

表中自定义名称只用于说明位置。**实际键帽仅显示固定内容**，例如 `zp`、`A12`、`+`，保留大小写，不附加功能名。新增八个自定义键初始固定公共库第一项，可分别长按更换。新装应用公共库为 `zp`、`c`，原 A 固定 `zp`、原 B 固定 `c`。

五行键盘独立计算高度，不把增加的行强行压入旧数字区高度；支持大小比例与横屏高度限制，长内容自动缩字并最多分两行。小屏、最小比例和横屏仍需按实际设备检查可读性。

## 全键盘布局编辑

长按全清 → 设置 → 按键布局。全部按键均可调整位置，不限功能列：

- 长按按键并拖到目标键，目标变亮后松手换位；也可依次点击源键和目标键。
- 数字 0 始终横占相邻两格。移动时，被占位置的普通键会移到 0 原来空出的格子；不能把 0 放到一行最后一列。普通键拖到 0 上时，按同样规则交换整块区域。
- 「左右镜像」翻转整个布局，并保持 0 的两格顺序。
- 「保存」才会应用并持久保存；「取消」、关闭键盘或切换输入框放弃未保存草稿。
- 「恢复默认」只修改布局预览，需保存后生效；不改变公共库、各键固定内容、型号库、大小或震动设置。

升级到本版本首次使用新的 5×5 默认排列，旧版五键功能列布局不直接套用到新网格；旧版位置配置保留在本机，但本版使用独立布局配置。原 A/B 固定内容及其他设置继续保留。

## 统一自定义库

所有 **10 个自定义键共用一个库**，每个键的固定内容独立。单击输入当前内容；长按打开公共库，点击候选只改变此键的固定内容，不向输入框提交文字。

首次升级自动按原 A 库顺序，再追加 B 库独有项；完全相同的内容去重，`A` 与 `a` 是不同项。原两个键的固定内容保留。迁移一次性写入新公共库，之后不会再次追加旧库中已删除的内容。

点击「编辑」可添加、修改、删除和拖动排序，操作作用于公共库：

- 每项允许 1–10 个 Unicode 字素字符，支持字母、数字、中文、运算符、标点、空格、换行、表情。保留内容原样，禁止重复和空项。
- 添加/修改使用深色文本编辑页，有常用符号插入按钮，可切换已安装输入法输入中文或主动粘贴。保存后返回原应用，如切换过输入法需切回商品键盘。
- 修改候选会同步更新所有引用它的自定义键，不改变候选顺序。
- 删除正在使用的项时显示受影响的自定义键编号，先选替代内容再删除；取消不会修改库或固定内容。所有受影响的键在同一次保存中切换到所选替代项。
- 至少保留一项，所有键共享候选排序。候选以 JSON 保存，逗号、引号等不会被拆分。
- 设置中的「恢复默认候选（公共库）」有确认页，会重置公共库及 10 个固定值，不改变布局或其他设置。

字符计数按设备 Android ICU 的字素边界处理，较新复合表情在旧 Android 版本上可能计为多个字符。

## 按键与连续输入

| 按键 | 单击 | 长按 |
|---|---|---|
| 全清 | 清空当前输入框，无二次确认 | 打开设置，不清空 |
| 自定义 | 原样输入固定内容 | 选择/管理公共库 |
| 数字及减号 | 按下立即输入一次，松开不重复 | 不连续重复输入 |
| 退格 | 删除选中内容或光标前一个 Unicode 码点 | 不连续删除 |
| 搜索 | 发送 Android IME_ACTION_SEARCH | 无额外动作 |

数字按下后的滑出或取消不撤销已经提交的字符；按下即亮、松手即灭。自定义、全清、退格和搜索保留松手判定。主键盘没有额外工具栏。

型号候选在约 80 ms 空闲后于后台读取输入框并匹配，主线程不等待查询返回；只保留最新待查请求，旧结果失效后不发布。手指触摸期间不刷新候选栏高度。目标应用自身处理文字的速度仍会影响体验。

## 型号候选与表格导入

长按全清 → 设置 →「输入后显示型号候选」（默认开启）。设置 →「导入型号」可选择 `.xlsx` 表格、型号列和是否跳过标题，预览后保存。最多 20000 项，每项最多 128 个字符且不能包含空白；去重，保留文本前导零及纯零数字格式，解压后上限 24 MB，不支持加密文件。取消或失败不覆盖旧型号库。

候选采用**包含匹配**，忽略大小写，按导入顺序最多显示 30 项，可横向滚动。例如输入 `13` 可匹配 `413`、`c-1357`。点击候选替换光标所在的整个型号，而非重复追加；选中后候选栏收起，继续编辑时恢复。只移动光标或重新打开键盘不会单独恢复。空内容、无匹配、选中文本及密码框不显示候选。

型号以空白分隔。候选收起状态仅在输入法进程中保留；支持完整文本提取的目标应用可检测外部粘贴变化。型号库与自定义公共库独立，恢复公共库不清除导入型号。

## 其他设置

- 上下拖动大小区域：上拖增大、下拖缩小，松手保存，范围 65%–100%。
- 按键震动默认关闭；开启后使用系统触觉反馈，声音始终关闭。
- 「触碰键盘外区域时收起」默认开启。触碰表格等外部位置即收起，不必等拖动；也会响应普通单击。关闭后恢复原行为。外部输入框可能由目标应用重新唤起键盘。
- 支持恢复默认大小、切换其他输入法。

## 安装、隐私与兼容性

下载 debug APK 安装后，打开「商品键盘」，依次启用并切换输入法，可在试输框验证。Google 表格需进入单元格或公式栏的文字编辑态；全清仅作用于当前编辑框，不清空整张表。前导零可通过将列设为纯文本保留。搜索动作需要目标应用支持，不会自动打开 Google 表格的查找框。

不申请 INTERNET、无障碍或悬浮窗权限，不联网、无广告统计，不保存输入历史。仅保存本地布局、候选及固定值、导入型号、大小和开关。系统备份关闭，不主动读取剪贴板；编辑页允许用户主动粘贴，拖动用 ClipData 作为拖放载体，不读写剪贴板。全清使用全选及空文本替换，不剪切；目标编辑器不支持全选时提示。

APK 为调试签名，不同电脑/CI 的签名可能不同，不能保证覆盖安装；卸载会丢失本地配置。真机 Google 表格、厂商导航栏、震动和触摸手感仍需验收，见 [测试记录](docs/TESTING.md)。应用未内置用户商品表或自行统计的默认词库。

## 构建与结构

JDK 17 或 21、Android SDK 35、Build Tools 35.0.0，AGP 8.8.0、Gradle Wrapper 8.10.2。在不提交的 `local.properties` 指定 sdk.dir，首次构建可能需下载依赖，应用自身不联网。

```sh
./gradlew assembleDebug assembleDebugAndroidTest lintDebug
# Windows
gradlew.bat assembleDebug assembleDebugAndroidTest lintDebug
```

安装包：`app/build/outputs/apk/debug/app-debug.apk`。专用设备可运行仪器测试，测试会重置配置，不要使用日用设备。

- `ProductIme.java`：输入法、设置、公共库管理和布局编辑。
- `CustomLibrary.java`：旧 A/B 库迁移、共享候选与十个独立绑定。
- `KeyLayout.java` / `KeyboardGrid.java`：5×5 布局规则及统一格子几何。
- `Preferences.java`：本地配置，保留旧版数据读取接口供迁移验证。
- `CandidateEditorActivity.java` / `CustomText.java`：文本编辑与字符校验。
- `SuggestionQuery.java` / `ModelMatcher.java` / `ModelWorkbook.java`：后台候选查询、型号匹配与导入。
- `app/src/androidTest/`、`tests/`：仪器与离线回归测试。
- `.github/workflows/android.yml`：GitHub Actions 构建及 APK/Lint 产物。

开发在 feature 分支，验证后提交并推送 GitHub；不自动合并 main。
