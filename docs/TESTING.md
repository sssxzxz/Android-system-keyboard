# 0.1.4 型号候选验收补充

- 导入含有「型号、价格」两列的表格，选择型号列后确认预览；价格不得进入候选。取消导入、无效文件或空列不得覆盖旧库。
- 验证文本 `0013`、纯零格式显示的 `00013`、数字 `1301`、共享字符串及行内字符串。
- 输入 `13`，显示匹配的完整型号；点 `1301` 后文本应为 `1301`，不能成为 `131301`。
- 在 `1302` 中间移动光标至 `13|02`，选择 `1301` 后应为 `1301`。其他空白分隔的内容保持不变。
- 退格、全清、粘贴、光标移动、切换输入框后候选须同步刷新。无匹配或空文本不占候选栏空间。
- 关闭设置开关并重新打开键盘，候选栏不显示；重启应用后开关和型号库仍保留。再次开启后恢复匹配。
- 密码框、选中文本时不显示候选。长按自定义候选的功能不受开关影响。
- 横竖屏和最小尺寸下查看候选栏、设置及导入预览，检查遮挡和滚动。确认手机原版签名可覆盖安装。
