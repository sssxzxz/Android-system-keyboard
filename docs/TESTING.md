# 第一版验收

## 0.1.2 布局自定义

编译、Lint（无错误）、签名及 6 项 Android 15 模拟器仪器测试通过。新增验证：布局默认值、右侧位置和顺序持久保存、未保存的草稿不影响原布局、恢复默认不改变大小/震动/候选，以及损坏或缺少功能键的配置保护。实际长按拖动退格到顶部、切换到右侧、保存回主键盘均通过截图和本机配置检查。

真机补充验收：长按任意位置的全清仍进入设置；取消后旧布局不变；恢复默认后点击保存；关闭重开键盘及旋转屏幕后布局保持；候选编辑与搜索维持原行为。
