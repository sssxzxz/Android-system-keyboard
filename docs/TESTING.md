# 第一版验收

自动检查：`./gradlew assembleDebug assembleDebugAndroidTest lintDebug`。
连接专用测试设备或模拟器后：`./gradlew connectedDebugAndroidTest`。
仪器测试会重置该设备上的商品键盘配置，请勿对已配置好的日用设备执行。

手机验收清单：
- 安装后能启用、切换商品键盘；退出应用仍能作为系统输入法使用。
- 数字依次输入，宽 0、00、减号正确，组合和字母输出小写。
- 光标移到中间、选中文字、多行输入时，全清删掉整个当前编辑框；不改变剪贴板。
- 长按全清只开设置，不误清空；长按组合/字母不误输入。
- 两类候选新增、重复新增、删除当前项、禁止删除最后一项、拖动前后排序。
- 重启输入法后候选顺序、当前值、大小、震动开关保持。
- 大小上拖增大、下拖缩小；恢复默认；横竖屏切换后仍可操作。
- Google 表格进入单元格编辑态后测试全部输入操作。
- 在不同 Android 版本与厂商机型上检查底部导航栏、震动、长按、拖动。
